## Why we built it

Most backtests lie. On daily or one-minute bars, a stop and a target can both sit inside the same bar, so the backtest has to guess which one was hit first. That guess is often wrong.

We ran the same strategies on bars and on 1-second data across 295 US stocks and ETFs, 2003–2026:

| Bar backtest | Looked profitable, wasn't second by second |
| --- | --- |
| Daily bars, target assumed first | **51%** |
| Daily bars, usual OHLC rule | **23%** |
| 1-minute bars, intraday strategies | **60%** |

That's why Matana Labs fills every stop, target and exit on second-level data, on every plan, including the free one. [Read the study →](https://matanalabs.com/research/bar-resolution-backtest-inflation/)

## The labs

Eight labs, one engine, one data set. A strategy moves from one to the next without exporting anything.

| Lab | What you do there |
| --- | --- |
| **Chart Lab** | Charts down to one-second bars with up to 23 years of history in one window. Renko, range bars, indicators, drawings, alerts and replay. |
| **Market Lab** | Watchlists, price, volume by hour and news for the markets you trade. |
| **Strategy Lab** | Build a strategy from blocks, or describe it in plain words and the AI builds it. The rules are always written back in plain words. |
| **Backtest Lab** | Run it on any period. Every fill checked second by second, commission included. |
| **Analysis Lab** | 31 checks rolled into one score out of 100: walk-forward, untouched out-of-sample, parameter shifts, costs ×2 and ×3, execution delay, Monte Carlo, crisis days and a random-entry benchmark. |
| **Optimization Lab** | Smart parameter search or a full grid. See which settings hold up across the whole map, not just the single best cell. |
| **Prop Lab** | Your backtest replayed through FTMO, Topstep, Apex, The5ers, FundedNext or your own rules from many start days: pass rate, days to pass, and what breaks it. Plus a demo account. |
| **Journal Lab** | Import trades from any broker, measure them, and compare them with a strategy tested on the same days. |
